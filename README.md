## Typing Speed Test
веб-тренажер для проверки и тренировки скорости слепой печати. Приложение позволяет отслеживать скорость набора текста и точность ввода в реальном времени

## Стек
* HTML 
* CSS 
* JS.

## Функционал
* Режим практики - тренировка отдельных букв в разных регистрах
* Режим проверка - полноценный тест с предложениями.
* Аналитика результатов - затраченное время, символов в минуту, ошибки.
* Перезапуск теста
* Визуальная индикация набора текста - зеленый правильно, красный ошибка.
